# elibukin.github.io

The root of Eli Bukin's GitHub Pages site. It holds one file, [`app-ads.txt`](app-ads.txt), which ad buyers check to confirm that ads in my Android apps are sold only through my AdMob account. Every app whose Play listing's website is under `https://elibukin.github.io/` is covered.

The apps' own pages live in their repos, for example [Steps GPS Route](https://elibukin.github.io/steps/).
